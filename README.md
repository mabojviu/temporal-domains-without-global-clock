# Collaborative relational time without a global clock

Public v2.0.0 reproducibility archive for the manuscript:

**Collaborative relational time without a global clock: Reconstruction, partial gluing, and gauge-invariant calibration structure in finite event networks**

## What is new in v2.0.0

The public record is broadened upstream. Rather than beginning effectively at temporal domains and late gauge structure, v2 exposes the full successor chain:

`regional informational locality -> conditional global-coordinate redundancy -> local-clock/calibration reconstruction -> collaborative reconstructibility -> active coordination -> temporal atlas/typed gluing -> optional scalarization/deconditioning -> CAL gauge/Hodge -> provenance-conditioned balance`.

This is the main conceptual change relative to v1.x. Historical v1.0.0 and v1.0.1 releases remain frozen.

## Central finite claim

Within explicit finite relational event models, temporal organization can be studied without treating a primitive global scalar clock as the sole constitutive object. Regional informational sufficiency can be separated from causal-domain claims; a global scalar coordinate can be representationally redundant once collective structure is supplied; staged local clocks/calibrations can reconstruct chronology under declared interfaces; some target temporal relations require genuinely joint local information and can be generated by bounded local microdynamics; downstream structures then support active lifecycle, typed gluing, affine holonomy, and finite gauge/Hodge/provenance-balance constructions.

## What this archive does **not** claim

It does not establish universal emergence of physical time, continuum spacetime, Lorentz symmetry, gravity, a preferred spatial geometry, physical spacetime curvature, generic many-body scalability, or a Noether charge. Collaborative complexity measures reconstructibility, not causal responsibility.
