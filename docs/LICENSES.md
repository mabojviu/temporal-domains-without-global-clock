# Licensing map

This v2.0.0 release candidate preserves the mixed-license structure already used by the public v1.x repository.

- Code under `code/`: BSD 3-Clause; see `licenses/LICENSE_CODE_BSD-3-Clause.txt`.
- Repository documentation, manifests, and released data/evidence metadata: CC BY 4.0; see `licenses/LICENSE_DOCS_DATA_CC-BY-4.0.txt`.
- The manuscript is included as the corresponding scholarly work. Journal/publication rights, if later assigned, take precedence over this repository packaging note.

The root `CITATION.cff` uses the code license field because CFF exposes one primary license value; this does not erase the separate CC BY 4.0 documentation/data notice.
